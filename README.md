# 🔹 **3. GQL – ISO Graph Query Language Research & Engine Design**
### 👉 Repository: **https://github.com/omk18p/GQL**

### 📘 Research Title  
**Comprehensive Review of ISO Graph Query Language (GQL):  
Grammar Simplification, Parser Efficiency, and AST Strategies**

Authored by **Atharva Khot, Omkar Patil, Vaibhav Kondekar**  
Mentored by **Prof. D. B. Kulkarni & Dr. Gajanan Chinchwadkar**

**Highlights:**

- 29% grammar rule reduction  
- Efficient parser-generation approaches (ANTLR vs Bison/Flex)  
- AST transformation strategies  
- Performance bottleneck analysis  
- Execution pipeline: Parsing → AST → Optimizer → Executor  
- Foundation for future open-source ISO GQL engines  

A deep dive into modern graph query engine architecture.
